# proportionality-tables-lesson
A 6th grade math lesson on proportionality using tables, designed for GitHub Classroom.
# Proportionality Tables Lesson

## Objective
Students will learn how to identify and extend proportional relationships using tables.

## Instructions
1. Open the file `tables.md` in this repository.
2. Complete the missing values in each table.
3. Commit your changes with a clear message (example: `Completed Table 1`).
4. Push your work to GitHub so your teacher can review it.

## Example Table
| Number of Pencils | Cost ($) |
|-------------------|----------|
| 2                 | 1        |
| 4                 | 2        |
| 6                 | 3        |
| 10                | ?        |

👉 Fill in the missing value by finding the constant ratio.

## Challenge
- Write a short explanation in `tables.md` about how you know the relationship is proportional.
- Bonus: Create your own proportional table (choose any context — sports, shopping, cooking).

## Submission
- Commit your completed tables and explanation.
- Push your changes to GitHub.
- Your teacher will review your work and leave feedback in your repository.
